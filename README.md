## Star schema

```
 DIM_STUDENT   DIM_ACADEMIC   DIM_LIFESTYLE   DIM_MENTALHEALTH   DIM_TIME
        \            \              |               /              /
                        FACT_DEPRESSION
         (depression_score, stress_score, anxiety_score, risk_level)
```
Grain: one student at one assessment date. Risk level from the PHQ-9 total: **Low 0-9, Medium 10-14, High 15-27**.
Dimensions also carry readable bands (e.g. `sleep_band`, `gpa_band`) for slicing. A view `vw_depression_flat`
joins everything for mining and the chatbot.

## LLM Data Assistant

Ask in English / Bangla / Banglish, e.g. *"Which department has the highest high-risk percentage?"*,
*"ঘুম কম হলে ঝুঁকি কতটা বাড়ে?"*, *"Show high-risk students with no counseling"*.

1. **Safety check** - first-person self-harm statements get a supportive message (999 / counseling service) instead of a query.
2. **Text-to-SQL** - the LLM writes one `SELECT`; it is validated (single statement, no comments, no write keywords), run on a
   **read-only** connection with a SQLite authorizer (only warehouse objects), capped at 200 rows; one automatic retry on SQL errors.
3. **Explanation** - the LLM explains the result in your language using only the returned numbers, plus mining insights
   (key factors, top association rules) as context.
4. **Conceptual questions** (PHQ-9, risk levels, what the model does) get a grounded answer.
5. **No API key / offline** - a rule-based fallback runs the built-in BI queries.

## Data mining notes

- Classification compares Logistic Regression, Decision Tree and Random Forest using **grouped** cross-validation and a
  **student-level** train/test split (no student in both). Depression/stress/anxiety scores and counseling are *not*
  features (they are the outcome or a consequence), so the model genuinely predicts risk from habits and academics.
- Expect modest, honest numbers (≈77% accuracy, macro-F1 ≈ 0.64 on the demo data); *Medium* and *High* are the hard classes.
- Findings are **associations**, not causes.

## Deviations from the proposal (deliberate)

- **SQLite** instead of MySQL/PostgreSQL for zero-setup (portable DDL in `warehouse/schema.sql`).
- **Streamlit + Plotly** instead of Power BI/Tableau (CSV exports open in Excel).
- Dimensions are loaded as *distinct-combination* dimensions; DIM_MENTALHEALTH keeps the scores shown in the diagram
  and adds severity levels.
